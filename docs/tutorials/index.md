# Tutorials

[Generate your first extension](first-steps.md) walks from a complete JSON Schema
to an importable module, then creates a PySTAC Item, writes extension values,
validates them, and round-trips the Item through JSON. The example runs locally
without a catalog service or remote schema downloads.
